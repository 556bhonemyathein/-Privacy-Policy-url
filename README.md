# Privacy Policy for Pocket Pilot

This repository serves as the public host for the official Privacy Policy documentation for the **Pocket Pilot** mobile application[cite: 1]. 

Pocket Pilot was developed as an offline-first utility designed to help users track personal finances, manage accounts, and monitor transactions without compromising their personal data[cite: 1]. We operate under a strict privacy-first principle: we believe your data belongs solely to you, which is why the application functions independently of external cloud servers or centralized tracking mechanisms[cite: 1].

---

### Key Privacy Principles

* **Zero External Data Collection:** Pocket Pilot does not collect, record, transmit, or monitor any personal or financial information on external servers[cite: 1].
* **Local-Only Storage:** All data entered into the application—including accounts, balances, categorized expenses, financial reports, and transaction histories—is kept strictly within local device storage[cite: 1].
* **No Third-Party Tracking:** The application integrates zero third-party tracking scripts, analytics tools, or behavioral advertising SDKs[cite: 1].
* **User Control & Deletion:** Because all information stays locally on your device, we have no access to your details, nor do we sell or transfer data to third parties[cite: 1]. Uninstalling the app or clearing its local storage permanently erases all associated data[cite: 1].
* **Minimal Device Permissions:** Any device-level permissions requested (such as local file storage access for generating local backups) are used strictly to deliver core app functionality and never to transmit data off-device[cite: 1].
